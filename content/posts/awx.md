In need of automation in your infrastructure? meet the AWX tool, the acronym stands for "Ansible Web eXecutable" is a free and open source project that allows you to easily manage and control your Ansible project. It provides a web-based user interface and a task engine created based on Ansible. Follow a step by step to install AWX using a docker in CENTOS8.
